# musical-waffle — 문명 스타일 턴제 4X 전략 게임

육각형 타일 지도 위에서 문명을 키우는 턴제 전략 게임입니다. 여러 단계로 나눠 만들고 있으며, 지금은 **1단계(지도 · 유닛 이동 · 턴 시스템)** 까지 구현되어 있습니다.

## 실행

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 빌드 도구, 서버, 외부 라이브러리가 필요 없습니다.

## 조작법

| 동작 | 마우스 / 키보드 | 터치 |
| --- | --- | --- |
| 유닛 선택 | 클릭 (같은 타일을 다시 클릭하면 겹친 유닛 전환) | 탭 |
| 이동 | 목적지를 우클릭해 경로 미리보기 → 한 번 더 우클릭해 확정 | 탭(또는 길게 누르기)으로 미리보기 → 한 번 더 탭해 확정 |
| 카메라 이동 | 드래그, WASD / 방향키, 미니맵 클릭 | 한 손가락 드래그, 미니맵 탭 |
| 줌 | 마우스 휠, `+` / `-` | 두 손가락 핀치 |
| 다음 유닛 / 턴 종료 | `Enter` 또는 오른쪽 아래 버튼 | 버튼 |
| 대기 / 경계 / 취소 | `Space` / `F` / `Esc` | 유닛 패널 버튼 |
| 안개 전체 해제/복구 (디버그) | `F2` | — |

## 파일 구조

```
index.html          화면 뼈대, 스크립트를 순서대로 불러옴
css/style.css       HUD·패널·새 게임 화면 (모바일 대응)
js/data.js          지형·특성·유닛·규칙·달력·카메라 수치 (밸런스는 여기서만 조정)
js/rng.js           시드 난수 mulberry32 (상태가 순수 데이터라 저장 가능)
js/hex.js           육각 좌표 계산 + 지도 좌표 계층 (동서 래핑은 여기만 고치면 됨)
js/mapgen.js        노이즈 기반 지도 생성, 시작 위치 찾기
js/state.js         게임 상태와 규칙: Rules / Vision / Units / Turn(processTurn) / State
js/pathfinding.js   A* 길찾기, 이번 턴 이동 가능 범위
js/render.js        Canvas 2D 그리기, 카메라, 미니맵, 유닛 애니메이션
js/input.js         마우스·키보드·터치 입력 해석
js/ui.js            상단 바·타일 정보·유닛 패널·알림·새 게임 화면
js/main.js          초기화, 게임 루프, 플레이어 행동(선택·이동·턴 종료)
```

모든 기능은 전역 객체 `Game` 아래에 붙어 있습니다(`Game.Data`, `Game.Hex`, `Game.State` …). 게임 상태(`Game.State.current`)는 DOM 요소나 함수가 없는 순수 데이터라 `Game.State.serialize()`로 JSON 저장·복원할 수 있습니다.
